# Portfólio oceânico

Projeto responsivo feito com HTML, CSS e JavaScript, inspirado nas imagens de referência.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.

## O que está incluído
- Página única com início, sobre mim, habilidades, projetos e contato.
- Layout responsivo com `@media`.
- Alternância claro/escuro com preferência salva em `localStorage`.
- Peixes animados nadando horizontalmente.
- Hover nas opções abaixo da baleia e nos cards.
- Animação de entrada das seções ao rolar a página.
- Formulário com máscara de telefone, validação e modal de retorno.
- Link para GitHub (substitua `https://github.com/` pelo seu perfil).

## Personalização
Troque os textos de exemplo, links de redes sociais e o endereço do GitHub pelos seus dados. O formulário está demonstrativo: para receber mensagens, conecte-o a um serviço de formulário/backend.
